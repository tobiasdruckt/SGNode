# SGNode 3D Print Files

This folder contains the 3D print files for SGNode:

- `Base.3mf`
- `Float.3mf`

The files are prepared as 3MF projects. Tested print settings are included in the files.

## Base

- Printer: Bambu Lab P1S
- Material: PLA
- File: `Base.3mf`

## Float

- Printer: Bambu Lab P1S
- Material: Creately translucent PETG
- File: `Float.3mf`
- Result: works well with only minor post-processing

## Ballast Weight

A print pause is included in `Float.3mf`. During this pause, insert two M10 washers as ballast weight.

Important:

- Insert both washers fully.
- Make sure they sit flat and do not protrude.
- Continue the print after inserting the washers.

## Post-Processing

After printing, check the mating surfaces and openings. Depending on printer, filament, and calibration, light post-processing may be required.

## Note

The float angle depends on material, print quality, sealing, and the inserted weights. After assembly, test the float in water and calibrate it before use.
