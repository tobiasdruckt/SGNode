# SGNode Branding Guidelines

## Logo
![Logo](https://github.com/SGNode/.github/assets/logo.svg)

## Color Palette
- **Primary Blue**: #1E40AF
- **Accent Purple**: #9333EA
- **Success Green**: #10B981

## Typography
- **Primary Font**: Arial, sans-serif
- **Secondary Font**: Courrier New, monospace

## Usage Rules
- The logo should be displayed prominently in all marketing materials.
- The primary color should dominate the layout.

## Component Definitions
- Buttons should be in Primary Blue with white text.
- Alerts should use Success Green for success messages and Accent Purple for warnings.
